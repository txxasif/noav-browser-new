Telegram Setup Guide

One-time setup: create a free Telegram API app to get your api_id and api_hash for “+ Add MTProto”.

Before you start
api_id and api_hash identify the application, not the account — one pair works for every Telegram account you add. Keep it private.

1 Log in to my.telegram.org

Open my.telegram.org and enter your phone number in international format. Telegram sends the login code inside the Telegram app, not by SMS — then press Next.

2 Open API development tools

On the “Your Telegram Core” page, click API development tools.

3 Create the application

Fill App title (e.g. My Meta) and Short name (e.g. mymeta), leave Description empty, leave the URL field empty and choose Platform → Desktop. Then click Create application and copy the api_id and api_hash it shows.

Choosing another platform (e.g. Android) can make the sign-in fail.
